# CI/CD流程设计文档

## 1. 分支策略 (Git Flow)

```
┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐
│  main   │◄────┤ release │◄────┤ develop │◄────┤ feature │
│ (生产)  │     │ (预发)  │     │ (开发)  │     │ (功能)  │
└────┬────┘     └────┬────┘     └────┬────┘     └────┬────┘
     │               │               │               │
     │  生产发布      │  版本发布      │  功能合并      │  功能开发
     ▼               ▼               ▼               ▼
   v1.0.0          v1.0.0-rc       自动部署dev      本地开发

┌─────────┐
│  hotfix │ ──► main (紧急修复)
│ (热修)  │
└─────────┘
```

## 3. 分支说明

| 分支 | 用途 | 保护策略 | 部署环境 |
|-----|------|---------|---------|
| main | 生产代码 | 禁止直接推送，需PR合并 | Production |
| release/* | 版本发布 | 禁止直接推送 | Staging |
| develop | 开发集成 | 需PR合并 | Development |
| feature/* | 功能开发 | 合并后删除 | 本地 |
| hotfix/* | 紧急修复 | 需PR合并 | Production |
