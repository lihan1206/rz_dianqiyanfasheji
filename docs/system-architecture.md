## 2. 服务间通信方式

| 通信类型 | 协议 | 使用场景 | 说明 |
|---------|------|---------|------|
| 外部通信 | REST API | 前端/第三方调用 | 使用JSON格式，HTTP/HTTPS协议 |
| 内部同步 | gRPC | 服务间实时调用 | 高性能二进制协议，用于高频调用 |
| 内部异步 | Message Queue | 事件驱动场景 | RabbitMQ/Kafka，用于解耦和削峰 |

## 3. 核心服务说明

### 3.1 项目管理服务 (Project Service)
- **职责**: 项目生命周期管理、版本控制、协作管理
- **端口**: 5000
- **数据库**: project_db

### 3.2 BOM管理服务 (BOM Service)
- **职责**: BOM结构管理、层级关系维护、变更追溯
- **端口**: 5001
- **数据库**: bom_db

### 3.3 元器件库服务 (Component Service)
- **职责**: 元器件信息管理、分类管理、供应商管理
- **端口**: 5002
- **数据库**: component_db
